Interactive prototypeCounter machine · writing slate · seller phone · customer phone
Drag to rotate · click the keys on the machine · scroll to zoom
  1. Pair. On the seller phone register, then enter the code shown on the machine (4821).
  2. Sell. Press Sell, tap products or press the ▥ Scan key. Review bill, take cash, print the receipt.
  3. Add stock. Stock → Write on slate. Click Undock slate, write with the mouse, then Recognise.
  4. Pickup. On the customer phone request an item. Accept it on the machine (Orders), mark ready, then enter the code from the customer phone.
